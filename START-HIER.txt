SCHULCOCKPIT V0.6.0 – GitHub Pages
===================================

Update wie bisher:
1. ZIP entpacken.
2. index.html, styles.css und app.js in deinem GitHub-Repository ersetzen.
3. Commit changes.
4. GitHub Pages aktualisiert die Seite.

WICHTIG IN V0.6
---------------
- Die ursprünglichen unveränderten Demo-Daten werden automatisch entfernt.
- Neue Installationen starten komplett leer.
- Am Wochenende springt das Cockpit automatisch auf die kommende Schulwoche.
- Der Stundenplan ist jetzt ein Raster: pro Block/Tag nur noch die Klasse auswählen.
- „Woche neu aufbauen“ entfernt falsche ungehaltene Wochen-Einträge, behält aber passende vorhandene Planungen.
- Unter „Setup importieren“ kannst du einen von ChatGPT erzeugten SCHULCOCKPIT_SETUP-Block einfügen.
  So können Daten aus Mein Schulplan / Screenshots / bisherigen Chat-Planungen gesammelt übernommen werden.

Deine lokalen Browserdaten bleiben bei normalen GitHub-Updates erhalten.
