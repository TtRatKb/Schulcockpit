SCHULCOCKPIT V0.7.0
====================

UPDATE AUF GITHUB
1. ZIP entpacken.
2. In deinem bestehenden GitHub-Repository die Dateien index.html, styles.css und app.js durch die neuen Dateien ersetzen.
3. Commit changes.
4. Deine im Browser gespeicherten Schulcockpit-Daten bleiben dabei erhalten.

WAS IST NEU?
- Neuer Bereich „Einrichten“ mit klarer Setup-Reihenfolge.
- Keine Demo-Unterrichtsinhalte mehr als Fallback.
- Datenprüfung auf widersprüchliche Stundenplan-/Klasseneinträge.
- Geführter Übernahmeweg aus „Mein Schulplan“.
- Button „Anfrage kopieren“, damit ChatGPT aus exportierten Unterlagen nur belegte Daten extrahiert.
- Setup-Import bleibt mit Vorschau und Auswahl, bevor Daten übernommen werden.

VORHANDENE DATEN AUS „MEIN SCHULPLAN“
Du musst nichts neu abtippen. Exportiere dort am besten:
- Wochen-/Tagesplan als Word oder PDF
- vorhandene Stoff-/Sequenzpläne

Lade diese Dateien anschließend im Chat hoch. ChatGPT kann daraus den SCHULCOCKPIT_SETUP-Block erstellen.

WICHTIG
Das Schulcockpit soll keine Klassen, Themen oder Reihen erraten. Fehlende Angaben bleiben absichtlich leer.
