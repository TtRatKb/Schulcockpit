SCHULCOCKPIT V0.3.0

GitHub-Update wie gewohnt:
1. ZIP entpacken.
2. index.html, styles.css und app.js in dein bestehendes GitHub-Repository hochladen.
3. Vorhandene Dateien ersetzen und committen.
4. GitHub Pages aktualisiert die Seite automatisch.

NEU IN V0.3
- Echte Materialdateien können im Browser gespeichert werden.
- Druckmengen gelten pro Unterrichtsstunde, nicht dauerhaft pro Datei.
- Materialien lassen sich direkt einer Stunde zuordnen.
- Standard-/Forder-/Förder-/DaZ-Versionen können jeweils eigene Dateien haben.
- Das Kopierzentrum erzeugt ein ZIP-Paket mit FARBE- und SW-Ordnern plus Druckliste.
- Arbeitsheft-/Buchseiten können ohne Datei als Ressource hinterlegt werden.

WICHTIG
Die hochgeladenen Unterrichtsdateien werden NICHT in GitHub gespeichert.
Sie liegen lokal im Browser (IndexedDB) auf dem Gerät, auf dem du sie hochlädst.
Normale Schulcockpit-Code-Updates unter derselben GitHub-Pages-Adresse löschen sie nicht.
