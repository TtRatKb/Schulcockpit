SCHULCOCKPIT V0.5.0
=====================

UPDATE AUF GITHUB
1. ZIP entpacken.
2. In deinem bestehenden GitHub-Repository die drei Dateien
   - index.html
   - styles.css
   - app.js
   durch die neuen Versionen ersetzen.
3. Commit changes.
4. Deine bisherigen Daten im selben Browser bleiben erhalten.

NEU IN V0.5
- ChatGPT-Planungen können wieder in eine konkrete Stunde importiert werden.
- In der Stunde: „1 · Brief kopieren“ → in ChatGPT planen → komplette ChatGPT-Antwort kopieren → „2 · Planung importieren“.
- Das Cockpit erkennt den <SCHULCOCKPIT_IMPORT>-Datenblock automatisch.
- Vor dem Import erscheint eine Vorschau.
- Du entscheidest per Checkbox, ob Thema/Ziel, Phasen, Folien, Materialien, To-dos und Status übernommen werden.
- Folienideen werden in der Stunde gespeichert.
- Offene Vorbereitungs-To-dos erscheinen automatisch in „Was jetzt?“.
- Materialtitel werden mit der Bibliothek abgeglichen; neue Materialien werden als Platzhalter angelegt.
- Druckmengen aus der Planung landen direkt beim Druckplan der konkreten Stunde.

WICHTIG
Die echten hochgeladenen Unterrichtsdateien bleiben weiterhin lokal im Browser (IndexedDB) und werden nicht in GitHub hochgeladen.
