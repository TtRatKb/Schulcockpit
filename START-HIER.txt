SCHULCOCKPIT V0.4.0
====================

UPDATE EINES BESTEHENDEN GITHUB-PROJEKTS
-----------------------------------------
1. ZIP entpacken.
2. In deinem GitHub-Repository die bisherigen Dateien ersetzen durch:
   - index.html
   - styles.css
   - app.js
3. Commit changes.
4. GitHub Pages aktualisiert die Seite automatisch.

WICHTIG
-------
- Keine versteckten Dateien.
- Kein npm / Terminal erforderlich.
- Deine bisherigen Browser-Daten aus V0.3 bleiben erhalten.
- Bestehende Stunden werden beim ersten Start automatisch in das neue
  Phasen-/Sequenzmodell übernommen.
- Hochgeladene Unterrichtsdateien bleiben lokal im Browser (IndexedDB)
  und werden NICHT zu GitHub hochgeladen.

NEU IN V0.4
-----------
- Sequenzen & grobe Jahresplanung
- Sequenzziele, Zeitraum und Klassenarbeits-/Leistungsdatum
- Unterrichtsstunden einer Sequenz zuordnen
- echter Phasenplan mit Phase, Minuten, Inhalt und optionalem Detail
- Phasen als tatsächlich geschafft markieren
- letzter Unterrichtsstand wird in der Folgestunde automatisch angezeigt
- offene Phasen aus der letzten Stunde mit einem Klick übernehmen
- ChatGPT-Brief enthält automatisch Sequenz, vorherige Stunde,
  tatsächlichen Stand, Materialien und Druckstatus
- Woche synchronisieren ordnet neue Stunden automatisch einer aktiven
  Sequenz zu, wenn der Zeitraum passt
